Équivalences interlinguistiques : validation collective

Merci de votre participation. Ce questionnaire présente dix rapprochements interlinguistiques proposés comme hypothèses de travail, puis une liste de marqueurs encore sans équivalent identifié.
Thank you for taking part. This questionnaire presents ten proposed cross-linguistic equivalences as working hypotheses, followed by markers for which no equivalent has been identified yet.

Comment répondre · How to answer

Partie 1 (1–10). Lisez la description de chaque rapprochement, puis indiquez dans quelle mesure vous êtes d'accord avec cette équivalence (1 = pas du tout d'accord, 5 = tout à fait d'accord), ou choisissez « NSP » si vous ne savez pas. Un commentaire libre peut être ajouté.
Read each description, then rate how far you agree with the proposed equivalence (1 = strongly disagree, 5 = strongly agree), or choose "Don't know". You may add a free comment.

Partie 2. Pour les marqueurs identifiés dans une seule langue, proposez si possible un équivalent couramment employé dans une autre langue.
For markers identified in one language only, suggest a commonly used equivalent in another language if you know one.

Aucune question n'est obligatoire : laissez vide ce que vous ne savez pas. · Nothing is mandatory: leave blank anything you are unsure about.
